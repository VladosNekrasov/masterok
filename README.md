# Мастерок: каталог мастеров Кузбасса

Площадка мастеров и услуг Кемеровской области: каталог с фильтрами по городам, анкеты, заявки, отзывы, жалобы, модерация и продвижение.

**Как запустить**: открыть сайт на GitHub Pages или любом статическом сервере. Настраивать ничего не нужно.

## Как устроено
- Сайт статичный: HTML, CSS и JS. Размещается на GitHub Pages.
- База данных локальная: Postgres (PGlite) работает прямо в браузере, данные хранятся в IndexedDB. Сервер не нужен.
- Регистрация мгновенная, без подтверждения по почте. Первый зарегистрированный аккаунт становится владельцем.
- Данные видны только в том браузере, где их создали. Копию можно скачать в панели, вкладка «Настройки». Там же владелец может стереть базу.
- Права и уведомления работают через правила и триггеры базы (`supabase/setup.sql`).

## Роли
| Роль | Что может |
|---|---|
| Владелец | Всё: продвижение мастеров, назначение модераторов, категории, настройки, удаление пользователей. Владельцем становится первый зарегистрированный аккаунт. |
| Модератор | Очередь проверки анкет и отзывов, жалобы, санкции (предупреждение, запрет отзывов или заявок, блокировка), отметка «Проверен», журнал. |
| Мастер | Анкета, услуги, фото, заявки, ответы на отзывы, оспаривание отзывов, запрос продвижения, режим «не принимаю заказы». |
| Пользователь | Заявки со статусами, отзывы, избранное, жалобы. |

## Файлы
- `index.html`: страница сайта
- `js/`: код сайта
- `css/style.css`: стили
- `js/localdb.js`: локальная база
- `supabase/setup.sql`: схема базы, применяется автоматически при первом запуске
- `vendor/`: иконки Phosphor и PGlite, лежат локально

Продвижение сейчас бесплатное: мастер запрашивает его в кабинете, владелец подключает в панели. Чтобы принимать оплату картой, понадобятся ЮKassa и небольшой сервер.
