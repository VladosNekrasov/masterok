# Запуск «Мастерка»: пошагово

Займёт около 20 минут. Понадобятся почта и аккаунт GitHub.

## 1. База данных Supabase

1. Зарегистрируйтесь на https://supabase.com (кнопка Start your project, можно войти через GitHub).
2. Нажмите **New project**:
   - Name: `masterok`
   - Database Password: придумайте и сохраните
   - Region: **Central EU (Frankfurt)**, ближе всего к России
   - Тариф Free
3. Подождите 1-2 минуты, пока проект создаётся.
4. Слева откройте **SQL Editor**, нажмите **New query**. Скопируйте всё содержимое файла `supabase/setup.sql`, вставьте и нажмите **Run**. Должно появиться `Success. No rows returned`.

## 2. Подключение сайта к базе

1. В Supabase откройте **Project Settings** (шестерёнка) и затем **API**.
2. Скопируйте **Project URL** и ключ **anon public**.
3. Откройте файл `js/config.js` в блокноте и вставьте их вместо `https://YOUR-PROJECT.supabase.co` и `YOUR-ANON-KEY`. Сохраните.

Ключ `anon` публичный, его можно выкладывать на GitHub. Ключ `service_role` никуда не вставляйте и никому не показывайте.

## 3. Публикация на GitHub Pages

1. На https://github.com нажмите **New repository**: имя `masterok`, тип **Public**, создайте.
2. Нажмите **uploading an existing file** и перетащите **всё содержимое** папки `masterok` (файлы и папки `css`, `js`, `vendor`, `supabase`, `index.html`, `.nojekyll`). Нажмите **Commit changes**.
3. **Settings**, затем **Pages**: Source **Deploy from a branch**, Branch **main**, папка **/ (root)**, **Save**.
4. Через 1-2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/masterok/`.

## 4. Адрес сайта в Supabase (для писем)

В Supabase откройте **Authentication**, затем **URL Configuration**:
- **Site URL**: `https://ВАШ-ЛОГИН.github.io/masterok/`
- **Redirect URLs**: добавьте тот же адрес.

Без этого ссылки из писем (подтверждение почты, сброс пароля) будут вести не туда.

## 5. Станьте владельцем

Откройте сайт и **сразу зарегистрируйтесь первым**, выбрав «Ищу мастера». Первый зарегистрированный аккаунт автоматически становится **Владельцем**. Кнопка «Управление» в шапке ведёт в панель.

В панели:
1. **Настройки**: впишите email и Telegram поддержки, проверьте города.
2. Разошлите мастерам ссылку `https://ВАШ-ЛОГИН.github.io/masterok/#/register?role=master`.
3. Новые анкеты появляются во вкладке **Очередь**, их нужно одобрить.
4. Модератора назначают во вкладке **Пользователи**: человек регистрируется как пользователь, вы меняете ему роль.

## Письма: важно

Бесплатная почта Supabase отправляет **всего несколько писем в час**. На старте лучше выбрать один из вариантов:
- **Проще всего**: Authentication, затем Sign In / Providers, Email и выключить **Confirm email**. Регистрация станет мгновенной, без письма.
- **Надёжнее**: подключить свою почту для отправки (Authentication, затем Emails, SMTP Settings). Подойдёт SMTP Яндекс Почты или Mail.ru.

Сброс пароля работает через письмо в любом случае.

## Полезно знать

- **Бесплатный проект Supabase засыпает**, если на сайт неделю никто не заходил. Тогда зайдите в панель Supabase и нажмите Restore. Пока на сайте есть посетители, проект не засыпает.
- Лимиты бесплатного тарифа: база 500 МБ и хранилище фото 1 ГБ. Это тысячи мастеров.
- Если сайт плохо открывается у части пользователей в России, причина обычно в блокировках адресов Supabase. Решение на будущее: перенос базы на российский хостинг. Код сайта при этом почти не меняется.
- Резервная копия: на бесплатном тарифе Supabase автоматических бэкапов нет. Раз в неделю скачивайте копию в панели сайта, во вкладке «Настройки», кнопка «Скачать копию».
- Обновить сайт: замените файлы в репозитории GitHub, Pages пересоберётся сам.
- Сменить права или роль вручную: Supabase, затем Table Editor, таблица `profiles`, колонка `role` (`owner`, `moderator`, `master`, `client`).
